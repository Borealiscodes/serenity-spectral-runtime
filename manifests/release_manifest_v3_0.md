# ⭐ 3 — Boundaries

This release **does not**:

- activate NDH geometry  
- introduce sealed‑layer logic  
- modify governance altitude  
- introduce new solver classes  
- activate spectral geometry  
- modify guardrail invariants  

v3.0 is strictly:

- expressive‑layer  
- schema‑layer  
- runtime‑external  
- manifold‑expansion  

All traversal remains reversible and drift‑neutral.
