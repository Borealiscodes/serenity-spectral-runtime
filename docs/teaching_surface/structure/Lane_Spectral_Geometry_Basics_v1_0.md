#### 2 — Core metaphors (spectral, not formal)

- **Soft manifold:** “a landscape that can bend without breaking”  
- **Spectral view:** “seeing how shapes hum or resonate”  
- **Envelope:** “a soft container around behavior”  
- **Tile:** “a small, safe patch of the landscape you can stand on”

All of these stay **metaphor‑grade**, not math‑grade.

---

#### 3 — Tile‑aligned traversal (Lane 1)

- **Orientation tile (🧭):**  
  - “What is spectral geometry, emotionally?”  
  - Forest Board: 3–4 concept clusters, no equations.  
- **Exploration tile (🔍):**  
  - “Different ways shapes can ‘hum’.”  
  - Forest Board + Sticky‑Notes: examples like strings, drums, grids.  
- **Deepening tile (🏗️):**  
  - “How envelopes keep behavior safe.”  
  - Sticky‑Notes: micro‑directives like “imagine a room that muffles sound.”  
- **Interaction tile (🤝):**  
  - “Questions about how things resonate.”  
  - Zen Board: prompts like “what would a calm shape sound like?”  
- **Synthesis tile (🌅):**  
  - “Spectral geometry as a way of listening to shapes.”  
  - Forest Board + Zen Board: summary + gentle reflection.
