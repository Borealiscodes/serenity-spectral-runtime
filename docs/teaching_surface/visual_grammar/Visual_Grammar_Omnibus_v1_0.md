# ⭐ 2 — Geometry Atlas

## 🟢 Allowed Geometry  
```
○   ◇   @
(circle, hexagon, spiral)
```

- ○ circle → presence, calm  
- ◇ hexagon → cooperative cognition  
- @ spiral → non‑linear evolution  

## 🔴 Disallowed Geometry  
```
▲   →   ⇢   ✦
(triangle, arrow, routing, radiance)
```

- ▲ triangle → hierarchy  
- → arrow → routing  
- ✦ radiance → activation  

These rules apply across **all lanes**.
