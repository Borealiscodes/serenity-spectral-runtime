# 🟦 **Expanded Hex Palettes (v2.0)**  
### *Teaching Surface • Expressive‑Layer • NDH‑External • Codex‑Aligned*

This expansion introduces **lane‑specific**, **tile‑specific**, and **interaction‑surface‑specific** chromatic palettes, all governed by the **Visual Grammar Codex**.

It extends the original **Hex Value Palette v1.0** into a full chromatic system for:

- Teaching Surface tiles  
- Teaching Surface lanes  
- Tile Interaction Surfaces  
- Emotional geometry cues  
- Accessibility glyphs  
- Stability ecology glyphs  

All palettes follow Codex rules:

- **no radiance**  
- **no orbital gradients**  
- **no routing‑direction gradients**  
- **no governance‑posture hues**  
- **no constellation adjacency**
