# 🟦 **Tile Interaction Surfaces — Canonical Definition (v1.0)**  
### *Expressive‑Layer • Pedagogy • A0–A2 • NDH‑External • Visual‑Grammar‑Bound*

Tile Interaction Surfaces are **expressive‑layer cognitive workspaces** embedded inside Teaching Surface tiles.  
They allow users to:

- organize questions  
- cluster exploration paths  
- attach sticky‑notes  
- preview narrative objects  
- traverse conceptual boards  
- maintain reversible cognition  
- explore lanes safely  

They are **not** runtime surfaces, solver surfaces, or governance surfaces.  
They are **expressive‑layer interaction primitives**.

---

# ⭐ 1 — Purpose of Tile Interaction Surfaces

Tile Interaction Surfaces exist to:

- give users a **place to think**  
- give tiles a **place to host content**  
- give pedagogy a **place to organize exploration**  
- give narrative objects a **place to rest**  
- give questions a **place to cluster**  
- give cognition a **place to be reversible**  

They transform tiles from static teaching units into **interactive cognitive manifolds**.

# ⭐ 3 — How Interaction Surfaces Bind to Tiles  
Each tile now has an **Interaction Surface Slot**.

### 🧭 Orientation  
- Forest Board (concept preview)  
- Zen Board (soft reminders)  

### 🔍 Exploration  
- Forest Board (concept clusters)  
- Sticky‑Notes (exploration paths)  

### 🏗️ Deepening  
- Forest Board (deep conceptual anchors)  
- Sticky‑Notes (micro‑directive clusters)  

### 🤝 Interaction  
- Zen Board (expressive interaction)  
- Sticky‑Notes (question clusters)  

### 🌅 Synthesis  
- Zen Board (dual‑lane references)  
- Forest Board (conceptual summary)  

This is the **tile → surface mapping** that Flow v2.1 will use.

# ⭐ 4 — Interaction Surface Rules (v1.0)

### **IS‑1 — Surfaces must be NDH‑external**  
No routing, no governance posture, no subsystem adjacency.

### **IS‑2 — Surfaces must be reversible**  
No one‑way transitions, no cognitive cliffs.

### **IS‑3 — Surfaces must be expressive‑layer only**  
No solver semantics, no runtime activation.

### **IS‑4 — Surfaces must be multi‑modal**  
Text + diagram + expressive cues.

### **IS‑5 — Surfaces must be gentle**  
Emotional geometry must remain Safe, Mild, or Aesthetic.

### **IS‑6 — Surfaces must be tile‑bound**  
Surfaces cannot exist outside tiles.

### **IS‑7 — Surfaces must be lane‑aware**  
Each surface must respect lane stability ecology.
