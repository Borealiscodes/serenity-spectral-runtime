# ⭐ 2 — Flow Modes (v1.0)

These are the **three cognitive traversal modes** that govern how a learner moves through the Teaching Surface.

### **Psychonaut Flow**  
- intuitive  
- metaphor-first  
- soft geometry  
- emotional safety priority  
- uses Zen Board heavily  

### **Architect Flow**  
- structural  
- pattern-first  
- tile sequencing  
- stability ecology priority  
- uses Forest Board heavily  

### **Developer Flow**  
- mechanical  
- clarity-first  
- envelope thinking  
- reversibility priority  
- uses Sticky‑Notes heavily  

These modes are **reversible** and **non-hierarchical**.

# ⭐ 3 — Flow Lanes (v1.0)

These are the **three teaching lanes**, now with traversal rules.

### **Spectral Flow (🔷)**  
- conceptual drift‑neutrality  
- gentle emotional geometry  
- Psychonaut → Architect transitions preferred  

### **Runtime Flow (📦)**  
- envelope thinking  
- soft runtime metaphors  
- Architect → Developer transitions preferred  

### **Emblem Flow (🎨)**  
- visual grammar  
- palette inheritance  
- Psychonaut ↔ Developer reversible transitions

# ⭐ 6 — Tone Axis & Emotional Geometry

### Tone Axis  
- gentle → neutral → mild → aesthetic  
- never sharp  
- never directive  
- always reversible  

### Emotional Geometry  
- 🫶 Safe (default)  
- ⚪ Neutral (structural tiles)  
- 🙂 Mild (runtime tiles)  
- 🌈 Aesthetic (emblem tiles)

All flows must be:

- reversible  
- NDH‑external
